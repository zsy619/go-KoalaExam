# 📡 API 接口规范

> KoalaExam RESTful API 完整规范，含错误码、鉴权、接口清单与 curl 示例。

---

## 1. 基础规范

### 1.1 统一前缀

```
所有接口前缀：/api/v1
健康检查：  /health  （无需鉴权）
管理后台：  /admin/v1  （仅超管）
```

### 1.2 统一返回结构

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "trace_id": "abc123def",
  "ts": 1700000000
}
```

- `code = 0` 表示成功，其他为业务错误码
- `trace_id` 用于链路追踪与日志关联
- 列表接口 `data` 为 `{ list: [], total, page, page_size }`

### 1.3 HTTP 方法

| 方法 | 用途 | 幂等 |
|------|------|------|
| GET | 查询 | 是 |
| POST | 创建 / 触发动作 | 否 |
| PUT | 全量更新 | 是 |
| PATCH | 部分更新 | 否 |
| DELETE | 删除 | 是 |

### 1.4 命名约定

- 资源名使用复数名词：`/users`、`/questions`
- 子资源用嵌套：`/users/:id/roles`
- 操作类接口用动词：`/auth/login`、`/exams/:id/start`
- 字段命名：`snake_case`（前后端一致）

## 2. 错误码规范

| 区间 | 含义 | 示例 |
|------|------|------|
| 0 | 成功 | - |
| 100xxx | 通用 | 100001 未登录 / 100003 无权限 / 100004 资源不存在 |
| 200xxx | 用户模块 | 200001 用户名已存在 / 200002 密码错误 |
| 300xxx | 题目模块 | 300001 题目不存在 / 300002 Excel 解析失败 |
| 400xxx | 试卷/考试 | 400001 试卷未发布 / 400003 考试时间窗口错误 |
| 500xxx | 阅卷 | 500001 阅卷失败 / 500002 主观题未评分 |
| 600xxx | 收藏 | 600001 已收藏 |
| 700xxx | 系统 | 700001 服务繁忙 / 700002 第三方依赖异常 |

**完整错误码见 `pkg/errcode/errcode.go`**

## 3. 鉴权

### 3.1 Bearer Token

除 `/auth/login`、`/auth/refresh`、`/health` 外，所有接口需 Header 携带：

```
Authorization: Bearer <access_token>
```

### 3.2 Token 生命周期

```
Access Token 有效期：2h
Refresh Token 有效期：7d（一次性使用）
Refresh Token 撤销：用户注销 / 改密码立即失效
```

### 3.3 关键接口签名（HMAC-SHA256）

```
POST /api/v1/exams/submit
Headers:
  X-Timestamp: 1700000000   # 5 分钟内有效
  X-Nonce: random_uuid      # 防重放
  X-Signature: hmac_sha256(timestamp + nonce + body, secret)
```

---

## 4. 限流

| 接口 | 限制 | 算法 |
|------|------|------|
| `/auth/login` | 5 req/min/IP | 滑动窗口 |
| `/auth/refresh` | 60 req/hour/user | 令牌桶 |
| 全局 | 200 QPS/IP | 滑动窗口 |
| `/exams/submit` | 10 req/min/user | 滑动窗口 |

超出返回 `code = 700003` + `Retry-After` Header

## 5. 接口列表

### 5.1 认证模块

#### POST /auth/login

```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"Pass123"}'
```

请求：

```json
{
  "username": "alice",
  "password": "Pass123"
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "user": {
      "id": 1001,
      "username": "alice",
      "nickname": "Alice",
      "role": 3,
      "avatar": "https://..."
    },
    "access_token": "eyJhbGc...",
    "refresh_token": "eyJhbGc...",
    "expires_in": 7200
  }
}
```

#### POST /auth/refresh

```bash
curl -X POST http://localhost:8080/api/v1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"eyJhbGc..."}'
```

#### POST /auth/logout

```bash
curl -X POST http://localhost:8080/api/v1/auth/logout \
  -H "Authorization: Bearer <token>"
```

### 5.2 用户模块

#### GET /user/profile

当前登录用户信息。

#### PUT /user/profile

```bash
curl -X PUT http://localhost:8080/api/v1/user/profile \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"Alice","avatar":"https://..."}'
```

#### POST /user/password/change

```json
{
  "old_password": "Pass123",
  "new_password": "Pass456"
}
```

#### GET /admin/users（管理）

```bash
curl http://localhost:8080/api/v1/admin/users?page=1&page_size=20&role=3&keyword=alice \
  -H "Authorization: Bearer <admin_token>"
```

#### POST /admin/users

```json
{
  "username": "bob",
  "password": "Pass123",
  "nickname": "Bob",
  "role": 3,
  "email": "bob@example.com",
  "class_id": 5
}
```

#### POST /admin/users/:id/reset-password

响应：`{ new_password: "RandomP@ss123" }`

### 5.3 题库模块

#### GET /questions

```bash
curl "http://localhost:8080/api/v1/questions?page=1&page_size=20&category_id=1&type=1&difficulty=2&keyword=HTTP" \
  -H "Authorization: Bearer <token>"
```

#### POST /questions

```json
{
  "category_id": 1,
  "type": 1,
  "difficulty": 2,
  "title": "HTTP 状态码 404 表示？",
  "options": [
    {"key": "A", "content": "服务器错误"},
    {"key": "B", "content": "资源未找到"},
    {"key": "C", "content": "未授权"},
    {"key": "D", "content": "禁止访问"}
  ],
  "answer": "B",
  "analysis": "404 Not Found 表示服务器无法找到请求的资源",
  "tags": ["HTTP", "前端"],
  "score": 2
}
```

#### POST /questions/import

Excel 批量导入。

```bash
curl -X POST http://localhost:8080/api/v1/questions/import \
  -H "Authorization: Bearer <token>" \
  -F "file=@/tmp/questions.xlsx" \
  -F "category_id=1"
```

### 5.5 考试模块

#### POST /exams

```json
{
  "title": "2024前端期中考试",
  "paper_id": 88,
  "start_time": "2024-12-20T10:00:00+08:00",
  "end_time": "2024-12-20T12:00:00+08:00",
  "duration": 90,
  "shuffle_q": true,
  "shuffle_opt": true,
  "anti_cheat": {
    "max_tab_switch_count": 3,
    "enable_fullscreen": true,
    "enable_copy_paste_block": true
  },
  "target_type": 2,
  "target_ids": [10, 11, 12]
}

# target_type: 1=按用户 2=按班级 3=开放
```

#### POST /exams/:id/start

```bash
curl -X POST http://localhost:8080/api/v1/exams/88/start \
  -H "Authorization: Bearer <student_token>"
```

响应：

```json
{
  "code": 0,
  "data": {
    "exam_id": 88,
    "record_id": 12345,
    "questions": [
      {"id": 101, "type": 1, "title": "...", "options": [...]},
      ...
    ],
    "duration": 90,
    "start_time": "2024-12-20T10:00:00+08:00"
  }
}
```

#### POST /exams/answer

```bash
curl -X POST http://localhost:8080/api/v1/exams/answer \
  -H "Authorization: Bearer <student_token>" \
  -H "Content-Type: application/json" \
  -d '{"record_id":12345,"answers":[{"question_id":101,"answer":"B","elapsed":42}]}'
```

#### POST /exams/audit

```json
{
  "record_id": 12345,
  "events": [
    {"type": "tab_switch", "payload": {"from":"visible","to":"hidden"}},
    {"type": "copy_attempt", "payload": {"question_id":101}}
  ]
}
```

#### POST /exams/submit

```bash
curl -X POST http://localhost:8080/api/v1/exams/submit \
  -H "Authorization: Bearer <student_token>" \
  -H "X-Timestamp: 1700000000" \
  -H "X-Nonce: $(uuidgen)" \
  -H "X-Signature: <hmac_sha256>" \
  -d '{"record_id":12345}'
```

响应：

```json
{
  "code": 0,
  "data": {
    "id": 12345,
    "status": "submitted",
    "submit_time": "2024-12-20T11:30:00+08:00"
  }
}

# 注意：成绩异步返回，需等 5-10s 通过 WebSocket / 轮询获取
```

#### POST /favorites/toggle

curl -X POST http://localhost:8080/api/v1/favorites/toggle \

  -d '{"target_type":1,"target_id":101,"folder_id":5,"note":"重点题"}'

{

GET /favorites/check?target_type=1&target_id=100

GET /wrong-book?mastery_level=0&page=1

### 5.7 统计模块

## 6. 分页约定

```
请求参数：
  page: 当前页（从 1 开始）
  page_size: 每页数量（默认 20，最大 100）

响应 data 格式：
  {
    list: [...],
    total: 123,
    page: 1,
    page_size: 20
  }
```

---

## 7. 时间格式

```
所有时间使用 ISO 8601 + 时区：
  2024-12-20T10:00:00+08:00

数据库存储：UTC DATETIME
接口返回：调用方时区（默认 Asia/Shanghai）
```
