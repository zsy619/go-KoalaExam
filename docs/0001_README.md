## 📐 文档约定

### 编号规则

- 4 位数字前缀（0001 - 9999），按推荐阅读顺序递增
- 同主题下保持原语义名称（ARCHITECTURE / API 等）
- 新增文档请插入到合适位置，编号顺序调整
- **专题分组**：考试（0015-0019）、其他专题从 0020 开始预留

### 文档质量标准

每篇文档应满足：
- [ ] 有清晰的目录（TOC）
- [ ] 有图 / 表 / 代码示例
- [ ] 有具体的数字（QPS / 延迟 / 阈值）
- [ ] 有维护者签名
- [ ] 每季度 review 一次

### 命名规范

- 文件名：`NNNN_TOPIC.md`（大写英文 + 下划线）
- 中文标题：使用 emoji + 主题
- 代码块：指定语言（```go / ```bash / ```sql）
