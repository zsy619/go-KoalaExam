## ✅ v1.0 MVP（已发布）

> **目标**：核心考试闭环

**核心功能**：
- ✅ 用户/权限（超管/教师/学生三级 RBAC）
- ✅ 题库管理（6 种题型 + Excel 导入）
- ✅ 三种组卷策略（手动/随机/遗传算法）
- ✅ 限时考试 + 防作弊（切屏/乱序/复制粘贴）
- ✅ 阅卷（客观自动 + 主观人工）
- ✅ 成绩统计（ECharts + Excel 导出）
- ✅ 深度收藏 / 错题本（核心卖点）

**技术指标**：
- 单实例 3,000 人同时在线
- P99 < 500ms
- 部署：Docker Compose / K8s

## 🚧 v1.1 性能优化版（Q1 2025）

> **目标**：支撑万人级并发，提升稳定性

### 功能
- [ ] 阅卷异步化（Redis Stream，已部分完成）
- [ ] 分布式锁（防止阅卷并发）
- [ ] 缓存预热（考试开始前 10 分钟）
- [ ] 答题 WebSocket 推送（替代轮询）
- [ ] 数据库读写分离（主写从读）

### 稳定性
- [ ] 全链路 TraceID 接入（OpenTelemetry + Jaeger）
- [ ] 完善 Prometheus 告警
- [ ] 混沌工程（Chaos Mesh 演练）
- [ ] 数据库 PITR 备份（恢复到任意秒）

### 体验
- [ ] 弱网断线续考（基于 LocalStorage + Service Worker）
- [ ] 移动端适配（响应式 + PWA）

### 关键指标
- P99 < 200ms
- 错误率 < 0.01%
- 同时在线 10,000 人

## 🎯 v1.2 功能增强版（Q2 2025）

> **目标**：好用、爱用

### 产品
- [ ] 题目协作（多人编辑 + 评审流）
- [ ] 试卷模板（一键复用）
- [ ] 智能题库推荐（基于错题率推相似题）
- [ ] 学习路径（知识点图谱 + 自适应学习）
- [ ] 学生画像（薄弱点雷达图）

### 防作弊
- [ ] 人脸识别（活体检测）
- [ ] 屏幕录制（教师监考回放）
- [ ] 异常行为 AI 检测（鼠标轨迹分析）

### 阅卷
- [ ] 代码题自动评测（对接 Judge0 / 自建沙箱）
- [ ] AI 主观题辅助评分（GPT-4 评分 + 教师确认）

### 集成
- [ ] 钉钉 / 企业微信登录
- [ ] 钉钉 / 飞书通知
- [ ] Webhook 对接（成绩推送）
- [ ] Open API（允许第三方调用）

## 🤖 v2.0 AI 智能版（Q3 2025）

> **目标**：从考试工具升级为智能学习平台

### 智能出题
- [ ] AI 自动出题（基于知识点 + 难度）
- [ ] 智能组卷（深度学习组卷模型）
- [ ] 题目质量评估（AI 辅助审核）

### 智能学习
- [ ] 自适应学习路径（基于艾宾浩斯遗忘曲线）
- [ ] 错题讲解（GPT-4 生成解析）
- [ ] 一对一 AI 助教
- [ ] 知识点图谱可视化

### 智能监考
- [ ] 视频流 AI 分析（异常行为识别）
- [ ] 多人脸追踪
- [ ] 异常声音检测

### 技术
- [ ] LLM 微调（教育领域专用模型）
- [ ] 向量数据库（Milvus / Qdrant）
- [ ] 流式推理（Triton / vLLM）

## 🏗 v3.0 平台化（2026 H1）

> **目标**：成为通用在线考试 / 学习平台

### 平台能力
- [ ] 多租户（每个机构独立数据）
- [ ] 插件市场（第三方扩展）
- [ ] 低代码组卷（可视化拖拽）
- [ ] 开放 API + Webhook
- [ ] SaaS 化部署（按租户计费）

### 行业垂直
- [ ] K12 校园版（题库 + 教务系统对接）
- [ ] 企业培训版（员工认证 + 课程体系）
- [ ] 驾校 / 医院 / 银行（专业题库）

### 技术
- [ ] 微服务化（按域拆分）
- [ ] Service Mesh（Istio）
- [ ] GitOps 交付（ArgoCD）
- [ ] 完整可观测性（Metrics + Tracing + Logging）
